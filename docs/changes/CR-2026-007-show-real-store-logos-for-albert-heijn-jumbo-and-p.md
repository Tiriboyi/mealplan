# CR-2026-007: Show real store logos for Albert Heijn, Jumbo and Plus

## Summary
`RetailerBadge` now shows the requester's logo files for Albert Heijn, Jumbo and Plus on a white tile, instead of the first letter of the store name. The files are imported as static images from `src/app/logos/`. Jumbo's wide wordmark gets a wider badge (`.wide`): 72 px, or 52 px below 720 px so the hero's "save €…" stays on one line at 360 px. All other stores keep the letter badge.

## Known limitations & follow-ups
- **Tested** for the class only: the 52 px phone width is a CSS-only follow-up commit, and jsdom can't observe layout. `done` warned that source changed without a test change. That width was checked by hand (see above), and no automated test covers it.
- Light mode was not checked by eye. The logos sit on a fixed white tile, so they should look the same in both themes (**assumed**).
- In the tests the AC-1 check compares image sources, not file names, because Vite inlines small assets as `data:` URIs.
- At 360 px the hero's Albert Heijn row still wraps "save €…" onto two lines. That was already the case before this change.
- At 26 px the Plus logo's "PLUS" text is too small to read. The four-leaf mark is still recognisable.
- The logo files (trademarks; Plus from seeklogo.com) are committed to the public repo, as decided at approval.
